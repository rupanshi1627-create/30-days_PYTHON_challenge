Object-Oriented Programming (OOP) – Introduction
Definition

Object-Oriented Programming (OOP) is a programming paradigm that organizes code into classes and objects. An object contains both data (attributes) and behavior (methods).

In simple words, OOP allows us to model real-world entities in a program by combining their properties and actions into a single unit.

Why OOP?

As programs become larger, writing only functions makes the code difficult to manage. OOP helps by organizing code into reusable and maintainable structures.

Advantages
Code reusability
Better organization
Easier maintenance
Improved readability
Suitable for large-scale applications
Promotes modular programming
Basic Terminology
1. Class

A class is a blueprint or template used to create objects. It defines the attributes and methods that its objects will have.

Example:

class Car:
    pass

Here, Car is a class.

2. Object

An object is an instance of a class. It is the actual entity created using the class.

Example:

class Car:
    pass

car1 = Car()
car2 = Car()
Car → Class
car1 → Object
car2 → Object
3. Attribute

An attribute is a variable that stores data about an object.

Example:

Brand
Color
Speed
4. Method

A method is a function defined inside a class that describes the behavior of an object.

Example:
start()
stop()
accelerate()
Real-World Example

Class: Car

Attributes:

Brand
Color
Speed

Methods:

Start()
Stop()
Brake()

Objects created from the class:

BMW
Audi
Honda

Each object belongs to the same class but has different attribute values.

Four Pillars of OOP
1. Encapsulation

Combining data and methods into a single unit (class) and restricting direct access to data.

2. Inheritance

A child class acquires the properties and methods of a parent class, enabling code reuse.

3. Polymorphism

The same method or interface can perform different actions depending on the object.

4. Abstraction

Hiding implementation details and exposing only the essential functionality.

Key Points
Class: Blueprint or template.
Object: Instance of a class.
Attribute: Data stored in an object.
Method: Function that defines an object's behavior.
Summary
OOP stands for Object-Oriented Programming.
It organizes programs using classes and objects.
Objects contain both attributes (data) and methods (behavior).
OOP makes code modular, reusable, maintainable, and easier to understand.
The four main principles of OOP are Encapsulation, Inheritance, Polymorphism, and Abstraction.
